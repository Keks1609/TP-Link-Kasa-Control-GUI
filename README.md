# Kasa Plug Controller

A lightweight tool to control TP-Link Kasa smart plugs directly from your computer.

## Features
- Discover Kasa devices in your local network
- Turn plugs on and off
    - Power off safety message before really turn off
- View real-time device status
- View real-time device power consumption
- Change device-name
- Simple and fast interface

## Platforms
- Windows (executable)
- Linux (AppImage)

## Usage
1. Launch the application
2. Scan for devices on your network
3. Select a plug
4. Toggle power or check its status

## Notes
- Ensure your computer is connected to the same network as your Kasa devices
- No cloud connection required – works locally
